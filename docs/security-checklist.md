# セキュリティ 運用チェックリスト

Moments Share合同会社 ／ 最終更新 2026-10-22

この規模の会社で実際に起きる事故は、ほぼ次の3つです。順番もこのとおりで、
サイトのコードの話はいちばん最後です。

1. **アカウントの乗っ取り** — どこかで流出したパスワードの使い回し
2. **共有設定のミス** — 見せるつもりのないファイルが公開になる（2026年に1回発生）
3. **放置された古いシステム** — 更新されないまま外から開ける状態で残っている

---

## A. 一度だけやる（終わったらチェック）

- [ ] **旧WordPress（Xserver）の処遇を決める**
      外から開けるか確認し、使わないならアクセス制限をかける。
      残すなら、サーバーパネルの「PHP Ver.切替」で最新版にする。
      ※「自動バックアップデータから復元」は選ばない
- [ ] **2段階認証（できればパスキー）** — まず次の3つ
      - [ ] ドメイン管理（取られると、サイトもメールも全部持っていかれる）
      - [ ] Googleアカウント
      - [ ] GitHub
- [ ] **2段階認証** — 次に
      Vercel ／ Xserver ／ マネーフォワード ／ X ／ Instagram ／ note ／
      Canva ／ Notion ／ Slack
- [ ] **ドメインの移管ロック**（レジストラの管理画面）
- [ ] **パスワード管理ツールを1つ決める**（1Password / Bitwarden）
      認証情報の共有はここだけで行う。メール・チャットでは送らない
- [ ] **共有設定の棚卸し**
      Googleドライブで「リンクを知っている全員」になっているファイルを直す。
      Canvaの編集用URLを外部に渡していないか確認する
- [ ] **GitHubの Secret scanning と Push protection を有効化**
      Settings → Code security。公開リポジトリなので無料。
      以後、APIキーなどを間違って入れても push の時点で止まる
- [ ] **IPA「重要なセキュリティ情報」のメール配信に登録**
      今回のPHPの件は X で知った。次からは直接届くようにする
- [ ] **Have I Been Pwned のドメイン監視に登録**（無料）
      自社ドメインのメールアドレスが流出したら通知が来る

## B. 毎月15分（カレンダーに繰り返し予定を入れる）

- [ ] Googleアカウントの「セキュリティ診断」を開いて、警告を消す
- [ ] **連携しているアプリ（OAuth許可）の一覧を見て、使っていないものを削除**
      ツールが多いので、ここがいちばん効く。1つ1つが入口になる
- [ ] 共有中のファイルで「リンクを知っている全員」のものを確認
- [ ] 辞めた人・終わったインターンのアクセスを削除
- [ ] Dependabot が作ったPRを確認して取り込む（下の「自動」参照）

## C. 自動で見張らせている（人は何もしない）

| 仕組み | 何をするか | 設定場所 |
| --- | --- | --- |
| Dependabot | 依存パッケージの更新PRを毎週月曜に自動作成 | `.github/dependabot.yml` |
| GitHub Secret scanning | 秘密情報の push を止める | GitHubの設定（要有効化） |
| セキュリティヘッダー | ブラウザ側で攻撃を遮断 | `vercel.json` の `headers` |
| Googleの不審なログイン通知 | 既定でON | スマホで受け取れるように |

## D. 事故が起きたときの初動

順番を間違えないこと。**先にパスワードを変える**。

1. そのサービスのパスワードを変更する
2. 「すべてのデバイスからログアウト」を実行する（変更前のセッションは生き残るため）
3. 連携アプリ（OAuth許可）の一覧を見て、身に覚えのないものを削除する
4. 同じパスワードを使い回していた他のサービスも、すべて変更する
5. 影響範囲（見られた可能性のある情報）を書き出す
6. 顧客の情報が含まれる場合は、隠さずに連絡する

---

## 覚えておくこと

- **「サイトが乗っ取られる」より先に、「アカウントが乗っ取られる」。**
  対策の順番を逆にしない
- **古いシステムを残したまま忘れるのが、いちばん危ない。**
  使わないものは閉じる
- **秘密情報をメールやチャットで送らない。**
  送った瞬間、相手の受信箱にも永久に残る
